# 求职工作台

面向求职者的个人信息管理系统：投递进度、简历管理、材料库、项目演示，一个页面全搞定。

纯前端应用，无后端、无账号体系——**所有数据只存在你自己的浏览器（IndexedDB）里**，支持一键导出/导入 JSON 备份。

## 功能

| 模块 | 能做什么 |
|---|---|
| 工作台 | 投递漏斗、进行中/面试中/Offer 统计、下一步待办、求职里程碑（可增删）、快捷入口 |
| 投递管理 | 投递台账（表格/看板双视图）：新增/编辑/删除，阶段流转（投递→笔试→一面→二面→HR面→Offer，挂/无消息可重开），每条投递可记面试纪（问到的题、答得不好的、要补的），目标公司候选池（可一键转投递） |
| 简历管理 | 个人资料池（教育/技能/实习/项目/荣誉/自评，逐条增删改查排序），多版本简历（如 AI 岗版/开发岗版，各自选择区块与条目），A4 实时预览，浏览器打印导出 PDF |
| 材料库 | 自我介绍/高频问题/项目深挖/八股分类管理；内置常用材料；支持上传本地 .md、页面内新建/编辑/删除（Markdown 渲染）；被修改的内置材料可一键重置 |
| 项目演示 | 对外展示的门户 + 双轴幻灯片（横向翻项目、纵向看演示页，键盘/拖拽/导航点）；内置交互演示页，可上传自己写好的交互式 HTML 页面作为演示 |

## 快速开始

需要 Node.js 24+。

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
npm run lint       # ESLint
npm run test:run   # 单元测试
npm run test:e2e   # Playwright 端到端测试
```

## 数据与隐私

- 数据保存在浏览器 IndexedDB（库名 `job-console`），**不上传任何服务器**；部署到公开的 GitHub Pages 也没有关系，别人打开是空的。
- 换浏览器/换电脑：用侧边栏「导出数据备份」下载 JSON，在新设备「导入数据」恢复。导入前会自动生成快照，误操作可回退。
- 简历、投递记录等隐私内容**永不写入代码仓库**；仓库里只有内置材料与演示配置。
- 隐私模式（无痕窗口）下 IndexedDB 不可用时，页面顶部会出现持久警告，此时数据关闭即失。

## 内容双通道（材料库与演示）

- **编译时通道**：把 md 放进 `src/content/library/`、交互 HTML 放进 `src/content/demos/`（文件名以 `项目id--` 为前缀），构建时自动收录。
- **运行时通道**：部署后的页面上直接上传 .md / .html，存入浏览器；两者合并展示，内置内容被修改后可重置。

## 部署（GitHub Pages）

推送 `main` 分支后，`.github/workflows/deploy-pages.yml` 自动执行 lint → 单测 → 构建 → 部署。首次启用需在仓库 Settings → Pages 把 Source 设为 GitHub Actions。构建使用相对路径（`base: './'`），用户主页与项目仓库子路径均可直接使用。

## 常见问题

- **换浏览器后数据没了？** 数据在本机浏览器里，跨设备请走「导出数据备份 / 导入数据」。
- **打印 PDF 排版不对？** 用 Chrome/Edge 的「打印 → 另存为 PDF」，纸张 A4、边距默认即可。
- **上传的演示页白屏？** 交互 HTML 需单文件自包含（内联 CSS/JS），不允许依赖本地同目录资源。
