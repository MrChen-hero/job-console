# 简历分页验收与编辑体验优化

日期：2026-09-18。Level 2，范围限简历模块、相关测试与文档。

## 目标与执行顺序

先关闭上一轮核查发现的分页与打印缺陷，再优化编辑和预览体验。分页修复已验收，界面设计已获用户明确确认并实施。

## 分页与打印

- 打印测量层隐藏时不得用零高度覆盖有效分页；处理窄屏编辑态直接打印、保存后打印与返回屏幕预览。
- 标题与首条内容作为同一放置单元；连续空区块标题也保持绑定直到下一内容块。组合超出整页时独占一页并允许溢出，不产生仅含标题的额外页。保持单趟扫描与零高度退化。
- 验收比较屏幕与稳定打印状态下每页的内容分配，并导出 PDF 检查物理页数。超高组合属于显式例外，不声称任意内容都能保持物理页数一致。

## 界面设计

沿用 Cool Slate 冷灰蓝、细描边、清晰信息层级；亮暗主题和窄屏均适配。

### 基本信息

- 顶部头像与说明整合成紧凑资料卡，减少大段说明占位。
- 字段按身份与教育、联系方式分组；姓名、学校、邮箱等长内容获得充足宽度，短字段成对排列，手机单列。
- 标签、输入框间距和底部保存操作统一；保留现有保存、失败保留和离开保护行为。

### 头像弹窗

- 桌面采用左右工作区：左侧裁剪取景，右侧上传区与缩放控制；手机纵向排列。
- 上传区使用原生按钮，支持点击、键盘与拖放单张 PNG/JPEG/WebP；显示拖入反馈、处理中与格式/大小错误。
- 点击与拖放共用解码、10MB 限制、1400px 压缩和裁剪初始化路径；取消或换图后旧异步操作不能覆盖新状态。
- 保留拖动裁剪、滑杆、滚轮、方向键及加减号；显示缩放百分比，提供恢复居中入口。

### 一页优先预览

- 采用紧凑但可读的单栏排版：收紧标题、条目、段落间距，页边距调整为上下 14mm / 左右 15mm；正文保持约 12px，不无限缩小内容。
- 纸面顶部将身份与联系方式合并为一个文字区域，头像保持右上角 25×35mm，减少文字区横向碎片。
- 无内容的区块不占标题空间；有内容时保持用户编排顺序和自定义标题。
- 常规示例（含头像）目标为一页，超长内容继续真实分页；预览与打印共享几何和样式，绝不截断或删除有效内容来凑页数。
